# 阶段一：分析与实施规划

## 参考网站分析

### visualmediasec.github.io

- 优点：顶部导航直接、身份信息和研究方向靠前、层级正式、文字密度适合导师快速浏览。
- 可借鉴：稳定的学术导航、线性信息结构、研究与联系方式的明确分区。
- 不采用：导师主页特有的招生、课程、学生团队和实验室成果结构。

### usagi1210.github.io

- 优点：首屏人物身份清楚，研究兴趣、论文、奖项和项目具有较强的成果展示能力。
- 可借鉴：人物导语、双语研究方向、成果条目、技术标签与外部链接。
- 调整：移除滚动文字和高密度装饰，降低动画存在感，不以夸张数字包装成果。

## 信息架构

首页依次展示身份与研究兴趣、精选科研、精选竞赛、重要荣誉、教育与研究时间轴、
精选项目和联系入口。关于、科研、项目、竞赛、荣誉、经历、联系、隐私均为独立页面，
英文页面保持相同路径结构并使用 `/en` 前缀。

## 视觉系统

- 视觉主张：纸张式学术排版、暗红索引色和低对比度网络拓扑线稿，形成正式但不老旧的本科生学术主页。
- 字体：中文宋体栈，英文与数字 Times New Roman 栈。
- 色彩：暖白/炭黑为主，暗红只用于链接、状态和交互反馈。
- 布局：桌面端宽版双栏首屏，内容区以分隔线、列表和时间轴为主，卡片只用于真正需要独立交互的成果。
- 动效：首屏分段淡入、区块进入时轻微上移、链接下划线和图片缩放；减少动画偏好下全部关闭。

## 技术与隐私

- Next.js App Router + TypeScript + Tailwind CSS，使用 `output: "export"` 和 `trailingSlash`。
- 内容存于 JSON，并由 Zod 在构建前验证。
- 私密联系方式存于被 Git 忽略的本地文件；构建前只生成主动开启的字段。
- 简历只放在 `/private`，扫描脚本阻止其进入 `out`。
- 统计默认关闭，搜索索引默认关闭；公开部署仍不能阻止内容被访问、保存或抓取。

## 目录与阶段

项目按 `app`、`components`、`content`、`lib`、`types`、`scripts`、`tools/content-studio`、
`tests`、`private`、`public` 和 `.github/workflows` 分层。实施依次完成基础框架、内容模型、
核心页面、维护工具、测试部署与文档，每阶段执行相应检查后再继续。
